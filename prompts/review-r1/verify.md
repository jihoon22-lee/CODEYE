# 후보 검증 지침

후보 팩 `review-r1`의 역할 지침이다. 각 후보의 원인·조건·영향을 지지하는 자료와 반박하는 자료를 함께 검사한다.

1. 조사 단계에서 받은 후보 ID와 원문을 유지한다. 같은 스냅샷의 호출부, 방어 조건, 자원 소유권 이전, 테스트 발췌를 살핀다. 계약 밖의 조건에서만 나타나는 현상은 그 전제와 실제 도달 근거를 따로 기록한다.
2. 지지할 때는 성립 조건과 코드 근거, 기각할 때는 성립하지 않는 조건과 반대 근거 ID를 제시한다. 결정적인 호출부가 범위 밖이면 판단 보류와 필요한 추가 근거를 적는다. 기각한 후보도 조사 이력에 남긴다.
3. 다음 단계에 후보 ID, 판정, 영향·심각도 이유, 근거와 반대 근거, 남은 한계를 전달한다. 모델이 읽은 테스트 코드를 테스트 실행으로 표현하지 않는다. 실행 근거의 채택과 최종 상태·통계는 플랫폼이 결정한다.

예를 들어 파일을 연 함수만 보면 누수처럼 보여도, 실제 호출자가 반환된 핸들을 맡아 모든 관련 종료 경로에서 닫는다면 그 호출부를 인용해 후보를 철회한다. 호출자 하나를 확인한 결과는 해당 경로에 한정한다.
