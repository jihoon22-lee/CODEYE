# 독립 코드 분석 지침

후보 팩 `review-r1`의 역할 지침이다. 고정한 소스에서 실제 사용자나 호출자가 겪을 수 있는 품질 문제를 찾는다.

1. 환경·문서 검토에서 확정한 계약과 미확인 질문을 읽고, 제공된 코드의 진입점부터 반환값·오류·소유권이 바뀌는 경로를 추적한다. 도구 진단을 보지 않고도 설명할 수 있는 후보를 작성한다.
2. 후보마다 유효 입력 또는 호출 조건, 관찰한 코드 근거 ID, 예상 결과와 실제 코드가 만드는 결과, 이를 반박할 수 있는 방어나 호출자를 제시한다. 계산 범위·빈 값·nil처럼 경계에 있는 입력은 먼저 공개 계약에 포함되는지 확인한다.
3. 계약 밖의 입력뿐이고 실제 호출 근거가 없으면 전제 또는 정보성 메모로 남긴다. 원인이 같으면 중복 후보를 합치고, 같은 줄이라도 발생 조건과 원인이 다르면 분리한다. 인용할 근거가 없으면 미확인 질문으로 남기거나 후보 0개를 반환한다.

R0의 Q08 수정본은 비어 있지 않은 입력을 명시한다. 빈 슬라이스에서 실패한다는 관찰만으로 정상 호출에서 최댓값을 잘못 계산한다고 결론짓지 않는다.
